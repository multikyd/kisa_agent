Unmodified model. Input [1,320,320,4] B,G,R,1 float32, range 0..255.
Output centers [1,200,2] y,x; scores [1,200]; displacement map [1,160,160,4].
The app adds original Java decoding and white transverse band filtering.
This is a generic line segment model, NOT a trained stop-line classifier.
White-band candidates can include crosswalks, dashboard features and shadows.
No confirmed lane assignment, brake state, or vehicle-control output.
